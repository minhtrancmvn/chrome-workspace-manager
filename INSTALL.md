# 📦 Workspace Manager Extension - Quick Install Guide

## For Users Receiving This Extension

### Installation Steps

1. **Extract the ZIP file** to a permanent location:
   - Mac: `~/Applications/` or `~/Documents/`
   - Windows: `C:\Program Files\` or `Documents\`
   - ⚠️ **Important**: Don't delete this folder after installation!

2. **Open Chrome** and go to:
   ```
   chrome://extensions/
   ```

3. **Enable Developer Mode**:
   - Find the toggle in the top-right corner
   - Turn it ON

4. **Click "Load unpacked"**

5. **Select the extracted folder** (the "Workspace Manager" folder)

6. **Done!** The extension is now installed ✅

### First Time Setup

1. **Pin the extension** (recommended):
   - Click the puzzle piece icon (🧩) in Chrome toolbar
   - Find "Workspace Manager"
   - Click the pin icon

2. **Create your first workspace**:
   - Click the extension icon
   - Enter a workspace name (e.g., "Work")
   - Choose a color
   - Click "Create Workspace"

3. **Open some tabs** and create more workspaces!

### Keyboard Shortcut

- **Mac**: `Cmd + Shift + W`
- **Windows/Linux**: `Ctrl + Shift + W`

### Features Overview

- 🪟 **Multiple Workspaces**: Organize tabs into separate windows
- 🎨 **Color Coding**: Assign colors to identify workspaces
- 💾 **Memory Saving**: Automatically closes inactive workspaces
- 📌 **Pinned Tabs**: Choose to share or separate across workspaces
- 💾 **Backup/Restore**: Export and import your workspace configurations
- 🏷️ **Badge**: Extension icon shows current workspace label

### Updating

When you receive a new version:

1. Download the new ZIP file
2. Extract and **overwrite** the old folder
3. Go to `chrome://extensions/`
4. Click the **refresh icon** (🔄) on "Workspace Manager"
5. Enjoy new features! 🎉
